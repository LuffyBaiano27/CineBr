# CineBR - Sistema de Venda de Ingressos 🎬

Este é um protótipo funcional de um sistema de venda de ingressos de cinema, desenvolvido com foco em performance, estética cyberpunk e uma experiência de usuário fluida. O projeto abrange desde a seleção de filmes e assentos até a confirmação de pagamento e emissão de ingressos.

## 🚀 Tecnologias Utilizadas
* **HTML5**: Estruturação semântica das telas.
* **CSS3**: Estilização com estética dark-mode e design responsivo.
* **JavaScript (Vanilla)**: Lógica de carrinho, gerenciamento de estado via `localStorage` e cálculos administrativos.

## ✨ Funcionalidades Principais
* **Sistema de Carrinho Inteligente**: Permite ao usuário selecionar filmes, datas, horários e assentos, mantendo os dados salvos durante a navegação.
* **Painel Administrativo**: Dashboards em tempo real com relatórios de vendas e gráficos dinâmicos.
* **Experiência do Cliente**: Histórico de compras, avaliação de filmes, suporte técnico e configurações personalizadas.
* **Easter Egg**: Homenagem especial escondida nas configurações do sistema!
* **Fluxo de Pagamento**: Integração simulada com métodos de pagamento (Cartão/PIX) e confirmação de compra com geração de ticket e download.

## 🛠️ Como executar o projeto
1. Clone este repositório para sua máquina local.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Não é necessário servidor backend; toda a lógica de dados é processada no lado do cliente (`Client-side`).

## 🎨 Design
O projeto segue uma paleta de cores escura com acentos em vermelho neon, proporcionando uma identidade visual moderna e imersiva, ideal para o público cinéfilo.
